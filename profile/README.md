# Arca Verborum

**A per-variety lexical database for computational historical linguistics.**
For each language variety, Arca Verborum keeps one reviewed construction built
from the best available lexical evidence, with full provenance, frozen variety
and concept identifiers, Glottolog/Concepticon/WordNet mappings, and a CLDF
export.

- **Explore:** [arcaverborum.org](https://arcaverborum.org) (latest release) ·
  [live.arcaverborum.org](https://live.arcaverborum.org) (current `master`)
- **Data and pipeline:** [arcaverborum/arcaverborum](https://github.com/arcaverborum/arcaverborum)
- **Releases:** identified as `<schema letter>-<date>`, e.g. `A-2026-11-10`,
  each with `full`, `redistributable` and `by` licence tiers and the
  accepted-inputs snapshot that rebuilds it.

Arca Verborum is built on top of [Lexibank](https://lexibank.clld.org), GLED,
Wiktionary and original sources, whose contribution is foundational. It began
as a way for students to use comparative lexical data without learning a
toolchain or cloning hundreds of repositories, and it stays static and
mirrorable: everything is in git and in archived releases.
